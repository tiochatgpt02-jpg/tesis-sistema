# Pruebas con docente y alumno

Esta guía propone observaciones humanas. No es un acta de pruebas ya realizadas. Usar cuentas ficticias para crear resultados de demostración y mantener privadas las cuentas reales.

| Caso | Acción | Resultado a comprobar |
| --- | --- | --- |
| Material y juego | Docente sube PPT, genera y revisa | Contenido corresponde al archivo; borrador no visible al alumno |
| Edición | Cambiar un juego publicado | Formulario comprensible; vuelve a revisión antes de publicar |
| Entrenamiento | Alumno juega y repite | Retroalimentación y puntos; libreta sin cambios |
| Práctica | Resolver y repetir una práctica | Resultado persistente y último intento del periodo en la fuente vinculada |
| Examen | Abrir vista previa, comenzar y finalizar | Vista previa sin reloj; intento congelado de treinta minutos desde Comenzar |
| Recuperación | Intentar otro examen y solicitar reapertura | Segundo inicio bloqueado; autorización docente habilita otro |
| Libreta | Registrar tareas, participación y libro | Guardado y recarga; prácticas y examen no admiten nota manual |
| Pendientes | Dejar una nota sin evidencia | Promedio pendiente; una nota cero sí se calcula |
| Historial | Entrar como alumno de cuarto con registro importado | Solo su historial literal AD/A/B/C; acceso ajeno rechazado |
| Calendario | Revisar fechas referenciales | Provisional y editable; cierre impedido hasta confirmación escolar |
| Modelo | Consultar ficha y un alumno sin historial numérico | Origen benchmark visible; sin historial no se inventa probabilidad |
| Persistencia | Cerrar sesión y volver a entrar | Datos conservados en PostgreSQL remoto |

Registrar fecha, rol, grado, equipo, tarea, duración, errores y ayuda requerida. El participante comenta si comprendió preguntas y controles. Marcar aceptación o pendiente con autor real; no completar un acta con respuestas simuladas.

La probabilidad del modelo no tiene un valor garantizado para notas bajas o altas y no debe describirse como certeza. Sus métricas públicas de referencia no prueban precisión institucional. Consultar [metodología](ml_methodology.md).

Para una sesión con alumnos y video, seguir el [protocolo del piloto](protocolo-piloto.md) y los procedimientos de autorización del colegio. Un recorrido automático de navegador no sustituye esta sesión.
