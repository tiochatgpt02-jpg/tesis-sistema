# Guía rápida de demostración

1. Abrir la URL de [la aplicación publicada](https://aula-computacion-tesis.onrender.com) antes de exponer. Ingresar con la cuenta docente de la hoja privada y abrir otra sesión como alumno.
2. Mostrar PPT, generar un juego y revisar su contenido con los formularios. Aprobar y publicar únicamente después de contrastarlo con el material.
3. Jugar desde la sesión del alumno. Mostrar que el resultado de entrenamiento no cambia la libreta.
4. Resolver una práctica y un examen publicados. Vincularlos en la libreta, distinguir tres notas manuales de tres automáticas y comprobar guardado. Usar cuentas ficticias para crear notas de demostración.
5. Consultar historial literal, calendario provisional y ficha del modelo. Explicar que un único bimestre no permite validar predicción futura del colegio.

No se requiere Ollama local. No usar credenciales antiguas de ejemplos como si fueran cuentas de nube. No generar notas reales ni confirmar el calendario escolar para simular una aceptación que aún falta.

Recorrido y explicaciones: [guía del jurado](guia_demostracion_jurado.md). Evidencia: [validación técnica](validacion-cambios-nube.md).
